# Wiki Cửa Hàng Implementation Plan

**Goal:** Add `/wiki/cua-hang` with every product in the 18 reachable VIP shop branches, its configured price, short description, requirements and ways to earn the payment currencies. Include the NPC's KNB conversion rates.

**Architecture:** Reuse AdminShell and Wiki styles. Read current buysell/goods/gamesetting/item files on the server, join by goods ID and GDPL/series, then provide a searchable, paginated client view. Resolve currency names from item templates rather than misleading INI comments. No dependencies or game changes.

**Scope:** Existing admin checkout, preserving prior work. This extends an established Wiki pattern. Only the reachable Cửa Hàng VIP catalog and KNB purchase menu are included; unrelated NPC shops and Kỳ Trân Các are outside this page's stated scope.

1. Add tests for real catalog coverage, currency joins, explicit prices, missing-price handling and accent-insensitive filtering. Run before implementing.
2. Add typed catalog loading and currency acquisition notes with source references. Missing evidence must remain unknown rather than become a zero/free price.
3. Add navigation, page, responsive product table, currency guide, search, shop/currency filters and pagination.
4. Run catalog tests, full tests, lint, typecheck and build; inspect rendered page where possible.

**Failure cases:** Missing or malformed rows, missing currency/template/price, repeated template variants, empty search, long descriptions, small screens. Show unknown prices honestly; report file read failures rather than silently omit a shop.

## Results

- Implemented 875 goods entries across all 18 VIP branches, 6 payment currencies and 7 acquisition guides (including the separate wallets used to buy KNB Đại).
- Found 6 entries whose duplicate GDPL/series templates disagree on Bạc prices. The page displays each configured price and source instead of claiming a load priority. Five entries lack corresponding templates; their goods price remains visible and the missing description/template is marked.
- Verified catalog joins, exact prices, conflicting prices, unknown-price handling, dangling goods, accent-insensitive search and currency filters with 3 new tests.
- Final verification: 71 tests passed, 3 MySQL integration tests skipped by configuration; lint, typecheck and production build passed. Tests/build were rerun outside sandbox after Windows blocked junction creation/output directories.
- Browser on existing localhost:3000: page loads, `phi phong` finds 20 entries, shop 204 finds 7 entries, Nguyệt Ảnh Thạch filter finds 145, empty/reset/pagination and currency anchors work. Duplicate-price example displays both 240,000 and 1,000,000 Bạc. At 390px viewport the document does not overflow horizontally; product table scrolls within its region.
- No game changes, database writes, service restarts or commits. Temporary port 3005 preview process stopped; the existing port 3000 development server was retained.
